Glicemia Fácil 3.0 — versão PWA

CONTEÚDO
- index.html: seu aplicativo original, com metadados PWA e registro do service worker.
- manifest.webmanifest: nome, ícones e comportamento de instalação.
- sw.js: cache do aplicativo para permitir abertura offline após o primeiro acesso.
- icons/: ícones do aplicativo.

COMO PUBLICAR
O PWA precisa ser servido por HTTPS (ou localhost). Não abra index.html diretamente por duplo clique.
Uma opção gratuita é publicar esta pasta no GitHub Pages.

IMPORTANTE SOBRE DADOS
O aplicativo original usa localStorage. Os dados ficam no armazenamento do navegador/perfil do dispositivo.
Instalar o PWA não importa automaticamente dados do navegador antigo nem sincroniza dados entre pessoas/dispositivos.
Faça backup JSON antes de migrar. Cada pessoa deve guardar seus próprios backups.
Limpar os dados do navegador ou desinstalar/limpar os dados do site pode apagar os registros locais.

TESTE
1. Publique os arquivos em HTTPS.
2. Abra o endereço no Chrome/Edge.
3. Aguarde o primeiro carregamento com internet.
4. No Android, use o menu do navegador > Instalar app / Adicionar à tela inicial.
5. Abra o aplicativo instalado e teste cadastro, medições, backup e restauração.
